# 🐈 Cat Facts Generator

A simple web application that displays random cat facts using the **Cat Facts API**. Click the button to fetch and display a new interesting fact about cats.

## 🚀 Features

* 🐱 Fetches random cat facts from an API
* 🔄 Generates a new fact with every button click
* 🎨 Simple and responsive user interface
* ✨ Interactive button effects using CSS

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API


## ⚙️ How It Works

1. The user opens the webpage.
2. The **Fact** button is displayed on the screen.
3. When the user clicks the button, JavaScript sends a request to the Cat Facts API.
4. A random cat fact is received and displayed inside the fact box.

The JavaScript uses the `fetch()` API to retrieve data and displays the first fact from the API response.
